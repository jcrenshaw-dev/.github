Tools for working with Claude Code and other AI coding agents.

| Tool | What it does | Status |
|---|---|---|
| [Terminus](https://github.com/jcrenshaw-dev/terminus) | Persistent, cross-session memory for Claude Code. Archives every session transcript losslessly and gives the model precise recall over its own history. | 1.0.0 released |
| [Baley](https://github.com/jcrenshaw-dev/baley) | Keeps AI coding agents accountable to the person who answers for their work. | Being built, not released |
| [Burnrate](https://github.com/jcrenshaw-dev/burnrate) | A single-file, local HTML report of your own Claude Code token usage. | Usable |
| [Sentinel](https://github.com/jcrenshaw-dev/sentinel) | The audit kit I run on my own tools, packaged as a Claude Code plugin. | Public to read, not supported for others to depend on |

Built by [John Crenshaw](https://github.com/crenshawdev). More at [jcrenshaw.dev](https://jcrenshaw.dev).
